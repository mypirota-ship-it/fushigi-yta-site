プライバシーポリシー（fushigi-yta）

最終更新日: 2026年11月19日

取得するデータ

fushigi-yta は、アプリ運営者本人の YouTube チャンネルについて、以下の Google API スコープで 読み取り専用のデータを取得します。

  • https://www.googleapis.com/auth/yt-analytics.readonly: 再生数、視聴時間、日別統計、視聴者維持率（区間ごとの視聴継続率・開始/終了回数など）
  • https://www.googleapis.com/auth/youtube.readonly: チャンネルの動画一覧、タイトル、公開日時、動画の尺などのメタデータ

動画のアップロード、変更、削除などの操作は行いません。

利用目的

取得したデータは、運営者自身のチャンネル運営の分析（どの動画のどの区間で視聴者が離脱したか等） のためにのみ使用します。

保存場所と管理

取得したデータと OAuth トークンは、運営者の管理するコンピュータ上のデータベースに保存します。 バックアップは運営者本人の Google Drive アカウント内にのみ作成します。 認証情報（トークン等）をバックアップに含めることはありません。

第三者への提供

取得したデータを第三者に販売、共有、提供することはありません。 Google API から取得した情報の使用は、Google API Services User Data Policy （Limited Use の要件を含みます）に従います。

アクセスの取り消しとデータの削除

利用者は、Google アカウントの「サードパーティ製のアプリとサービス」の設定から、 いつでも fushigi-yta のアクセス権を取り消すことができます。 保存データの削除を希望する場合は、下記連絡先までご連絡ください。
